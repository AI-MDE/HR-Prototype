# Audit

`mde audit [scope]` (said to the agent: there is no `mde audit` tool to run)

A second agent judges what no script can: whether the work is genuine. It is never the agent that did the work. **The audit covers every Target in scope, not only the architecture.**

1. **Who audits.** The agent that receives `mde audit` starts a sub-agent to do the audit, when its tool can start one (a fresh context, given only this page and the scope), and keeps out of its judgment. When it cannot, it says so and asks the user to open a new session and say `mde audit` there. An agent that built the output never audits it in its own context.
2. **Which Targets.** Every Target in scope: without a scope, each completed Target ([`work/targets.json`](../metamodel/work/targets.md): its records `completed`) whose audit is missing or older than its completion, limited to the scopes its records name. Named Targets are audited whatever their dates (one in progress, to judge it before it is completed). Name them before starting, and audit each; skipping one is reported, never silent.
3. **What it judges, for each.** Each concern of `targets/audit/<target>.md`, limited to the scope, by reading the Specs and driving the running application; never taking the code's comments, the tests' names, or the Evidence's statuses as its witness. Tests are claims: it judges whether they are honest. A Check met by its shape alone (a placeholder, a stub, a folder or a diagram with nothing behind it) is fake, whatever `mde verify` reported. For the architecture Target, each architecture decision (each leaf section of `specs/architecture/`) as written: resolved, traceable, and consistent ([Architecture Audit](../metamodel/evidence/architecture-audit.md)), never the code. For the server and the web UI, each decision that output realizes: where, and whether its code conforms (the report's *Conformance* section). **Each output is judged on its own Target**: code against the architecture on the Target that produced the code.
4. **What it writes.** One [Audit Report](../metamodel/evidence/audit-report.md) per Target, `evidence/audit/<target>.md`: each concern with its verdict (genuine, fake, or not exercised, with why), its witness (what it observed), its severity, and its fix, ending with the summary line *N genuine · M fake · K not-exercised*. For the architecture, the [Architecture Audit](../metamodel/evidence/architecture-audit.md), `evidence/audit/architecture.md`, one row per decision. Each fake on an in-scope concern is also a [Finding](../metamodel/work/finding.md).
5. **Then.** For each Target audited, write `audited` (the time the report was written) on its completed records in `work/targets.json`, whatever the verdict: the report says what was found, the date only that it was judged. Run `mde verify` again, so the Evidence Package counts the reports, and report in Status which Targets were audited and which were not.

The audit judges; it does not fix. The user decides on its findings, through `mde review`.
