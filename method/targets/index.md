# Targets

What good looks like for each kind of output, and how to check it. Each Target is compiled from the Features that impact it, with its checks in `verification/` and its audit concerns in `audit/`; [`catalogue.json`](catalogue.json) lists them. See the [README](README.md) for how a Target is compiled and how the Strategy uses it.
