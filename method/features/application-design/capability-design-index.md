# Capability design index

## Purpose

The "Capability design index" rules of the application-design Target that no other Feature supplies.

## Impact on application-design

It records the capability's primary entity, its module boundary (what it owns and what it consumes from other capabilities), and references to its entities, use cases, and pages. It is an index, not a re-narration: operations live on entities, behavior in use cases, contracts in API Contracts, pages in their own specs. Restating them creates two copies that drift apart.
